# English Speaking Practice

这是给 AI 陪练使用的表达清单。

## 表达

[打开表达清单](expressions.md)

清单中每行是一条我主动积累过的英语表达。陪练时：

- 先读取 `expressions.md`；
- 根据我想表达的意思，从清单中挑选合适表达；
- 我卡壳时先提示清单里的表达；
- 正常对话时不要打断纠错；
- 我说“结束练习”后，再统一反馈；
- 没有合适表达时，才补充新的表达。

## 开始使用

把这个仓库链接发给 AI，并告诉它：

> 请读取 https://github.com/yaqxuan/english-speaking-practice/blob/main/expressions.md。这是我积累过的英语表达。和我练习对话或独白时，请优先帮助我使用这些表达；我卡壳时先给提示，不要在对话中途纠错。我说“结束练习”后，再统一反馈。

练习结束后，如果有值得新增的表达，AI 可以直接把新的英文表达追加到 `expressions.md`；没有写入权限时，应该把需要追加的表达列出来，不要假装已经更新。

仓库公开，请不要加入私人信息。

## 长期同步约定

5Ad 是表达卡片的主要积累库。以后用户明确新增或确认保留表达时，陪练清单也要同步更新：

- 先读取最新的 `expressions.md`，按核心表达查重；同一表达的不同场景只保留一行。
- 将 5Ad 中新增且值得长期练习的核心表达追加到 `expressions.md`；规范化明显的变体（例如 `end up` 的 `-ing` 用法）后再查重。
- 只同步表达本身，不同步学习进度、私人笔记、例句或网站数据。
- 写入后回读文件并提交变更；没有写入权限时，明确列出尚未同步的表达，不要假装已经更新。
